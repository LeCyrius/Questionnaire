# QCM Microbiologie — Terminale STL

Questionnaire en ligne (100 questions, 7 thèmes). Les réponses et le score restent dans le navigateur de l'élève.

## Publier sur GitHub Pages

1. Créez un dépôt sur [GitHub](https://github.com/new) (par exemple `qcm-microbiologie-stl`).
2. Dans le dossier du projet, poussez les fichiers :

```bash
git init
git add .
git commit -m "Publication du QCM Microbiologie STL"
git branch -M main
git remote add origin https://github.com/VOTRE_IDENTIFIANT/qcm-microbiologie-stl.git
git push -u origin main
```

3. Sur GitHub : **Settings** → **Pages** → **Build and deployment** → source **Deploy from a branch**, branche **main**, dossier **/ (root)** → **Save**.
4. Attendez une à deux minutes. Le lien du site apparaît en haut de la page **Pages** :

`https://VOTRE_IDENTIFIANT.github.io/qcm-microbiologie-stl/`

Ce lien ouvre directement le QCM dans le navigateur.
